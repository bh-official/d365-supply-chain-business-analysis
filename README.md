# Supply Chain Business Analysis Portfolio

## Project Overview

This portfolio demonstrates my learning and application of Business Analysis techniques within Microsoft Dynamics 365 Finance & Operations, with a focus on Supply Chain Management, Trade and Logistics.

The project uses a fictional manufacturing company to explore business processes, identify operational challenges and propose improvements supported by ERP capabilities.

## Business Scenario

A fictional manufacturing company sources components from suppliers, manages warehouse inventory and delivers finished products to customers. The company faces challenges with purchase order visibility, stock discrepancies, delayed deliveries and supplier invoice mismatches.

The objective is to analyse the existing processes, document business requirements and recommend improvements to operational efficiency, data accuracy and reporting.

## Project Objectives

- Analyse procurement, inventory and order fulfilment processes.
- Document as-is and to-be business process flows.
- Identify process gaps, risks and improvement opportunities.
- Prepare business requirements, user stories and acceptance criteria.
- Develop user acceptance testing scenarios.
- Define key performance indicators to measure business outcomes.
- Explore how Microsoft Dynamics 365 Finance & Operations can support the proposed processes.

## Business Analysis Deliverables

1. Business case and problem statement
2. Stakeholder analysis
3. As-is and to-be process mapping
4. Business requirements and user stories
5. Gap analysis and recommendations
6. User acceptance testing scenarios
7. Requirements traceability matrix
8. Supply chain KPI analysis

## Technology and Tools

- Microsoft Dynamics 365 Finance & Operations: learning and process research
- GitHub and Markdown: project documentation and version control
- Mermaid: business process diagrams
- Microsoft Excel: sample data analysis and KPI calculations

## Project Status

Learning portfolio in progress. This project uses a fictional business scenario and proposed workflows. It is not a live Dynamics 365 implementation and does not represent professional implementation experience.

## Expected Outcomes

The project aims to demonstrate structured problem-solving, requirements analysis, process improvement, stakeholder awareness, testing and an understanding of supply chain business processes.
